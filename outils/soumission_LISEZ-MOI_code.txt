CODE · Défi 1 · Anticiper le risque de décrochage scolaire, région par région
==========================================================================

Noms des fichiers : ÉQUIPE_ÉTAPE_DÉFI_RÔLE_description_vN (équipe Biiga).

LES NOTEBOOKS JUPYTER (déjà exécutés : résultats et figures visibles sans rien lancer)
  Biiga_02-nettoyage_D1_engineer_notebook-nettoyage_v1.ipynb
      Lecture du fichier du challenge, 8 contrôles de cohérence, nettoyage des sources externes.
  Biiga_03-transformation_D1_architect_notebook-transformation_v1.ipynb
      Correspondance 13 / 17 régions, panel région × année, agrégat de violence (ACLED), carte des 13 régions.
  Biiga_04-analyse_D1_analyst_notebook-analyse-descriptive_v1.ipynb
      Ce que montrent les données, figures 01 à 07.
  Biiga_04-analyse_D1_scientist_notebook-modeles_v1.ipynb
      Risque de chute des effectifs, alertes de septembre et de janvier, apprentissage automatique,
      facteurs, formule du risque, score global, facteur dominant.
  Biiga_05-interpretation_D1_analyst_notebook-interpretation_v1.ipynb
      Figures de la solution, données du tableau de bord, fiches régionales.

  Chaque notebook commence par une cellule qui contient tous ses imports. Chaque étape y est un script
  du projet (les fichiers …_script-…_v1.py de chaque dossier d'étape), découpé en cellules. Les figures y sont allégées (JPEG) pour le dépôt.
  Pour les lire : Jupyter, VS Code, ou tout lecteur de notebooks.

LES ARCHIVES
  Biiga_05-interpretation_D1_analyst_tableau-de-bord_v1.zip
      Le code de l'application (Next.js), qui fonctionne sans réseau. Voir son README.md.
      Lancer : npm install, puis npm run build, puis npm start (http://localhost:3000).
      Sans base de données, l'application utilise les données publiées avec elle.
  Biiga_05-interpretation_D1_scientist_projet-complet_v1.zip
      Tout le projet, pour tout relancer : scripts, données traitées, tableaux de résultats,
      source LaTeX du rapport, application. Les notebooks, figures et PDF n'y sont pas :
      le code les régénère.

POUR TOUT RELANCER (Python 3.13)
  1. Décompresser le projet complet.
  2. Ajouter les données brutes, qui ne sont pas fournies (seules les données traitées le sont) :
     - le fichier du challenge : le télécharger dans l'espace challenge et le placer tel quel dans 01_collecte/brut/ ;
     - les sources publiques : les télécharger aux adresses données dans 01_collecte/brut/LISEZ-MOI.md,
       et les placer aux chemins indiqués.
  3. pip install -r requirements.txt
  4. python outils/construire_notebooks.py
     (chaque dossier d'étape a son LISEZ-MOI.md, qui décrit ses fichiers)
  Relancés, les notebooks redonnent exactement les mêmes résultats.

Le code est en anglais (fonctions, variables) ; les textes lus par l'utilisateur sont en français.
