CODE · Défi 1 · Anticiper le risque de décrochage scolaire, région par région
==========================================================================

Noms des fichiers : ÉTAPE_DÉFI_RÔLE_description_vN (sans nom d'équipe, pour l'évaluation à l'aveugle).

LES CAHIERS JUPYTER (déjà exécutés : résultats et figures visibles sans rien lancer)
  02-nettoyage_D1_engineer_cahier-nettoyage_v1.ipynb
      Lecture du fichier du challenge, 8 contrôles de cohérence, nettoyage des sources externes.
  03-transformation_D1_architect_cahier-transformation_v1.ipynb
      Correspondance 13 / 17 régions, panel région × année, agrégat de violence (ACLED), carte des 13 régions.
  04-analyse_D1_analyst_cahier-analyse-descriptive_v1.ipynb
      Ce que montrent les données, figures 01 à 07.
  04-analyse_D1_scientist_cahier-modeles_v1.ipynb
      Risque de chute des effectifs, alertes de septembre et de janvier, apprentissage automatique,
      facteurs, formule du risque, score global, facteur dominant.
  05-interpretation_D1_analyst_cahier-interpretation_v1.ipynb
      Figures de la solution, données du tableau de bord, fiches régionales.

  Chaque cahier commence par une cellule qui contient tous ses imports. Chaque étape y est un script
  du projet (scripts/*.py), découpé en cellules. Les figures y sont allégées (JPEG) pour le dépôt.
  Pour les lire : Jupyter, VS Code, ou tout lecteur de cahiers.

LES ARCHIVES
  05-interpretation_D1_analyst_tableau-de-bord_v1.zip
      Le code de l'application (Next.js), qui fonctionne sans réseau. Voir son README.md.
      Lancer : npm install, puis npm run build, puis npm start (http://localhost:3000).
      Sans base de données, l'application utilise les données publiées avec elle.
  05-interpretation_D1_scientist_projet-complet_v1.zip
      Tout le projet, pour tout relancer : scripts, données traitées, tableaux de résultats,
      source LaTeX du rapport, application. Les cahiers, figures et PDF n'y sont pas :
      le code les régénère.

POUR TOUT RELANCER (Python 3.13)
  1. Décompresser le projet complet.
  2. Ajouter les données brutes, qui ne sont pas fournies (seules les données traitées le sont) :
     - le fichier du challenge : le télécharger dans l'espace challenge et le placer tel quel dans data/raw/ ;
     - les sources publiques : les télécharger aux adresses données dans data/raw/LISEZ-MOI.md,
       et les placer aux chemins indiqués.
  3. pip install -r requirements.txt
  4. python scripts/construire_notebooks.py
     (ou suivre l'ordre des commandes du README.md, étape par étape)
  Relancés, les cahiers redonnent exactement les mêmes résultats.

Le code est en anglais (fonctions, variables) ; les textes lus par l'utilisateur sont en français.
